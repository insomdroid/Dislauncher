# Dislauncher — Play Store Mockups

These promotional concepts use the **original screenshots already stored in this repository**. No interface screens were fabricated for the mockups; the English headlines and captions are presentation copy.

## Mockups

- [Play Store Feature Graphic](PlayStore_Feature_Graphic.svg) — three-screen overview with the message “Less clutter. More focus.”
- [Play Store Feature Story](PlayStore_Feature_Story.svg) — two-panel feature story focused on the home screen and interface.

## Source screenshots

The SVG mockups reference the original PNG files in this folder through their raw GitHub URLs. If a preview client blocks externally linked SVG images, open the PNG source screenshots directly or download the SVG and view it in a browser.

## Notes

- Visual direction: dark mode, restrained mint-green accents, clean typography.
- Copy: English.
- These are concept layouts for review, not final Play Console exports. Confirm required dimensions and export to PNG/JPEG before uploading to Google Play.
