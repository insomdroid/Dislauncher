The idea

Your phone should work for you, not compete for your attention.

Dislauncher puts clear text and useful information ahead of a wall of icons. Keep favourite apps close, find the rest quickly, and shape your Home screen around the way you actually use your phone.

Good to know

A few quick answers.

Need more detail? The project repository contains the source code, documentation and release notes.

Which Android versions are supported?

Dislauncher supports Android 8.0 (Oreo) and later.

How do I install Dislauncher?

Download the APK from the latest GitHub release, open it and follow Android's installation prompts. Depending on your device settings, Android may ask you to allow installs from the app used to open the APK. Review the linked APK safety notes if Android displays a warning.

Does Dislauncher need every permission?

No. Some permissions are only relevant to specific integrations, such as showing device calendar events or notification indicators. Review each permission prompt and enable only the features you want to use.

Can I use my own look and layout?

Yes. Dislauncher offers theme and accent options, wallpaper, font and text-size choices, gestures, layout preferences and optional Home screen tools.

Are Notes and Calendar built in?

Yes. Dislauncher includes Notes, Calendar, Calculator and Unit Converter. Calendar can show local tasks and reminders, and device calendar events when you enable that integration.

Where can I check the code and privacy details?

Visit the GitHub repository, read the privacy information, or review the APK safety notes.
