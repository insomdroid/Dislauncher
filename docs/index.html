A few things to know.

Which Android versions are supported?

Dislauncher supports Android 8.0 (Oreo) and newer. Some optional features depend on the Android version and permissions available on your device.

How do I set it as my Home app?

Install the APK, then choose Dislauncher when Android asks which Home app to use. You can also select it in your device's Default apps settings.

Can I find apps outside my favourites?

Yes. Open the app drawer to browse or search installed apps. You can also organise apps into folders, hide apps and use compatible icon packs.

Which file types does Books support?

The built-in reader supports EPUB, PDF and TXT files. It includes bookmarks and reading progress, with a table of contents when the file provides one.

Do Notes and Calendar work offline?

Notes are stored on your device. Calendar includes local to-dos and reminders, and can show device calendar events when you grant calendar access.

Why does Dislauncher ask for permissions?

Permissions are tied to optional features, such as device calendar events, notification indicators or location-based weather. You do not need to enable features you do not use.

Is Dislauncher free?

Yes. Dislauncher is free and open source, with no ads, no analytics and no account requirement. The source code is available on GitHub.

Can I try changes before a stable release?

Yes. Nightly builds let you test recent changes before they are included in a stable release. They may contain unfinished work.
