Features

What you can do with Dislauncher

Use a text-first Home screen, organise apps, customise the interface and open everyday tools without switching to separate utility apps.

01 / HOME

Clock, date and favourite apps

Clock, date, progress indicators and favourite apps, with optional battery, weather, calendar agenda, music controls and notification indicators.

02 / APP ACCESS

Search and organise apps

Searchable alphabetical app drawer, favourites, folders, hidden apps, icon-pack support and shortcuts for common actions.

03 / PERSONALISATION

Themes, fonts and layout

System, light, dark and black themes, accent colours, wallpapers, font choices, text sizing, gestures and layout preferences.

04 / NOTES

Notes with formatting

Create notes with text formatting, lists, checklists and images. Search or pin notes, switch between list and grid views, and import or export notes.

05 / CALENDAR

Monthly calendar and agenda

Browse the month, choose a date and review its agenda. Local tasks and reminders can sit alongside events from your device calendar when enabled.

06 / EVERYDAY TOOLS

Calculator and unit converter

Use the built-in calculator, revisit previous calculations, and convert common measurements.

FAQ

Frequently asked questions

Which Android versions are supported?

Dislauncher supports Android 8.0 (Oreo) and later.

How do I install Dislauncher?

Download the APK from the latest GitHub release, open it and follow Android's installation prompts. Depending on your device settings, Android may ask you to allow installs from the app used to open the APK. Review the linked APK safety notes if Android displays a warning.

Which permissions does Dislauncher use?

No. Some permissions are only relevant to specific integrations, such as showing device calendar events or notification indicators. Review each permission prompt and enable only the features you want to use.

Can I change fonts and themes?

Yes. Dislauncher offers theme and accent options, wallpaper, font and text-size choices, gestures, layout preferences and optional Home screen tools.

Are Notes and Calendar built in?

Yes. Dislauncher includes Notes, Calendar, Calculator and Unit Converter. Calendar can show local tasks and reminders, and device calendar events when you enable that integration.

Where can I check the code and privacy details?

Visit the GitHub repository, read the privacy information, or review the APK safety notes.
