Features

What you can do with Dislauncher

Use a text-first Home screen, organise apps, customise the interface and open everyday tools without switching to separate utility apps.

01 / HOME SCREEN

A quieter Home screen

Keep up to six favourite apps within reach. Choose from four clock layouts, and show optional battery, weather, calendar, network, music and notification information.

02 / APP DRAWER

Find apps without an icon grid

Browse an alphabetical app list, jump through letters, search, create folders, hide apps you do not need and use compatible icon packs.

03 / BOOKS

Read EPUB, PDF and TXT files

Open books in the built-in reader, keep your files in one library and switch between Grid and List views. Reading works offline.

04 / NOTES

Write and organise Markdown notes

Format notes with Markdown, preview your writing, use lists and checklists, add images, search and pin notes, and import or export your work.

05 / CALENDAR

See your month and daily agenda

Browse a monthly calendar and review events for a selected day. Keep local tasks and reminders alongside device calendar events when you enable calendar access.

06 / EVERYDAY TOOLS

Calculate and convert

Use the built-in calculator for everyday and advanced calculations, then convert common measurements such as length, weight, temperature, speed and area.

07 / APPEARANCE

Make the interface yours

Choose System, Light, Dark or AMOLED-friendly appearance, adjust accent colours and text size, select bundled fonts, set wallpapers and customise gestures.

08 / PRIVACY

Use only the integrations you need

No account is required. Optional features request their related Android access only when needed. The source code and privacy notes are available to review.

Permissions and source code

Your phone, your choices.

Dislauncher does not need an account. Optional integrations use Android permissions or system access only when you turn on the related feature.

Optional access

Enable only what you use.

Calendar events need calendar access. Notification indicators use notification access. Weather may use location when you enable location-based weather. Music controls rely on Android media sessions. You can leave optional integrations turned off.

FAQ

Frequently asked questions

Which Android versions can run Dislauncher?

Dislauncher supports Android 8.0 (Oreo) and newer. Some optional features depend on the Android version and permissions available on your device.

How do I make Dislauncher my Home app?

Download the APK from GitHub Releases, install it, then choose Dislauncher when Android asks which Home app to use. You can also select it in your device's Default apps settings.

What can I do on the Home screen?

Keep up to six favourite apps on the Home screen. You can choose a clock style and turn optional information on or off, including battery, weather, calendar agenda, network details, music controls and notification indicators.

How do I find apps that are not favourites?

Open the app drawer to browse the alphabetical app list or search by name. You can also organise apps into folders, hide apps and use compatible icon packs.

Which files can the Books reader open?

The built-in Books reader supports EPUB, PDF and TXT files. Add books to your library and read them offline. The library can be shown in Grid or List view.

Do Notes and Calendar need an internet connection?

Your notes, local tasks and reminders are stored on your device. Notes supports Markdown, preview, search, pinning, images, and import or export. Calendar can also show events from your device calendar when you grant calendar access.

Why does Dislauncher ask for permissions?

Permissions are tied to optional features. Calendar access is used to show device events; notification access is used for notification indicators; and location may be used for location-based weather. Music controls use Android media-session access. You do not need to enable features you do not use.

Is Dislauncher free, and does it collect analytics?

Dislauncher is free and open source. It has no ads, does not require an account and does not include analytics. Read the privacy information or inspect the source code.

Can I try changes before a stable release?

Yes. Nightly builds let you test recent changes before they are included in a stable release. They may contain unfinished work, so use the latest release for everyday use.
